# Serveur_gmod

## Le site


Dans un premier terminal, on lance :

```
cd accueil/backend
```

```
npm start 
```

On lance dans un autre terminal :

```
cd accueil/frontend
```

```
npm run dev
```


### Se promouvoir en admin


-Allez dans le fichier promote-admin.js
-Mettez votre ID steam 

-Exécutez :

```
node .\accueil\backend\promote-admin.js 
```
